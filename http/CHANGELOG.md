# Changelog

All notable changes to this project will be documented in this file.

## [2.0.0] - 2024-01-01

### Added
- Complete modular HTTP component architecture
- PSR-7 HTTP Message implementation (Request, Response, Uri)
- PSR-15 Middleware support
- PSR-17 HTTP Factory implementation
- CodeIgniter 3 backward compatibility layer
- PHPUnit test suite with Unit and Integration tests
- Support classes: HeaderBag, ParameterBag, CookieBag, ServerBag
- Exception hierarchy for HTTP errors
- Helper functions for URL generation

### Changed
- Refactored from monolithic structure to modular architecture
- Updated to PSR-4 autoloading
- Implemented PSR-12 coding standards
- Enhanced type safety with strict typing

### Deprecated
- None

### Removed
- None

### Fixed
- None

### Security
- Initial secure release

## [1.1.0] - Previous Version

### Added
- Basic HTTP functionality
- Simple request/response handling
